# 02 Sub Account & 권한 관리 / 02 Sub Account와 접근 제한

이후 모든 실습을 수행할 작업 계정을 생성한다. 로그인 접속키를 생성하고, Sub Account를 만들고, 그 계정으로 로그인하여 권한이 없는 상태를 확인한 뒤 2차 인증을 설정한다. 권한은 다음 섹션에서 부여한다.

## What you will learn

- 로그인 방식의 차이 — 메인 계정은 이메일, Sub Account는 접속키와 로그인 아이디와 비밀번호. 접속키는 전역에서 고유한 값이며 생성하지 않으면 로그인 자체가 불가능하다
- Sub Account 생성 화면이 정하는 넷 — 누구인가, 어디로 접근하는가, 어디에서 접근하는가, 어떻게 로그인하는가
- 로그인 아이디를 변경할 수 없다는 점과 그것이 계정 이름 짓기에 미치는 영향, 그리고 자동 생성 비밀번호가 한 번만 표시된다는 점
- 계정 보안의 두 축 — 인증 강화(MFA)와 접근 위치 제한. 권한과 다른 종류이며, 위치 제한은 접속 장소가 고정된 환경에 적합하다
- 메인 계정과 작업 계정을 분리하는 이유, 그리고 계정이 존재한다는 것과 권한이 있다는 것의 차이
