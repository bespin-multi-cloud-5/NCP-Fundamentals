# 02 Sub Account & 권한 관리 / 03 그룹으로 권한 관리

앞 섹션에서 생성한 작업 계정에 권한을 부여한다. 계정에 직접 부여하지 않고 그룹을 거치는 방식을 사용하며, 정책을 교체하면서 권한이 어떻게 달라지는지 확인한다.

## What you will learn

- 정책을 부여하는 두 경로 — 계정에 직접 부여하는 방식과 그룹을 거치는 방식. 그룹을 사용하면 권한을 변경하는 지점이 하나가 된다
- 관리형 정책과 사용자 정책의 선택 기준, 그리고 사용자 정책 생성 시 지정하는 항목
- 정책 이름이 담는 것 — 계정 전체 범위 정책은 자원 축과 결제 축으로 나뉘고, 환경에 따라 자원이 나뉘는 서비스는 정책도 둘이다
- 권한이 화면에 나타나는 두 층위 — 정책이 없는 서비스는 메뉴에 표시되지 않고, 메뉴가 표시되는 서비스 안에서도 권한 밖 작업은 실행 시점에 차단된다. 차단 안내는 부족한 액션 이름을 표시한다
- 그룹을 삭제해도 소속 계정과 정책은 남는다는 점, 그리고 실습 권한을 넓게 설정한 이유와 실무와의 차이
