# 03 Compute - Server / 03 Block Storage

서버에 스토리지를 추가로 연결하고 서버 안에서 사용할 수 있는 상태까지 구성한다. 콘솔이 수행하는 범위가 어디까지인지, 연결 이후에 무엇이 남는지를 다룬다.

## What you will learn

- 기본 스토리지와 추가 스토리지의 구분 — 추가 스토리지는 서버가 없어도 생성되고 서버를 참조하는 자원이라 서버를 반납해도 남는다
- 볼륨 타입이 성능을 결정하는 방식 — CB는 크기가 IOPS를 정하고 FB는 고정이며, IOPS는 입력하는 값이 아니다
- 콘솔이 수행하는 범위 — 연결까지이며 파티션과 포맷과 마운트는 서버 안에서 수행한다
- 장치 이름은 하이퍼바이저를, 파일시스템은 배포판을 따른다는 점과 `/etc/fstab`에 UUID로 등록하는 이유
- Snapshot의 용도와 타입별 저장 방식 — CB2와 FB2는 변경분만 저장한다

## Examples

- `lab05` → 추가 스토리지 생성과 서버 연결, 파티션·포맷·마운트, `/etc/fstab` 등록, 재시작으로 마운트 유지 확인, 연결 해제와 반납
