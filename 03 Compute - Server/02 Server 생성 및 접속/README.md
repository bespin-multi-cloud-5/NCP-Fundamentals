# 03 Compute - Server / 02 Server 생성 및 접속

서버를 실제로 생성하고 SSH로 접속한다. 생성 절차의 여섯 단계가 무엇을 결정하는지, 접속이 성립하려면 무엇이 갖춰져야 하는지, 그리고 생성된 자원을 관계에 따라 어떤 순서로 반납하는지를 다룬다.

## What you will learn

- 서버 생성 여섯 단계가 각각 결정하는 것 — 이미지, 배치, 스토리지, 인증키, ACG
- 접속 경로를 이루는 셋 — 공인 IP, ACG 규칙, 관리자 인증. 하나라도 빠지면 접속이 성립하지 않는다
- 공인 IP가 서버와 별개의 자원이라는 점 — 서버를 반납해도 남고 보유만 해도 과금된다
- 인증키의 역할 — SSH 인증이 아니라 관리자 비밀번호를 확인하는 수단이며, 생성 절차 중간에만 내려받을 수 있다
- 자원 관계가 삭제 순서를 정한다는 점 — 의존은 해제할 수 없고, 참조는 해제하거나 참조하는 쪽을 삭제하며, 생성된 자원은 생성한 쪽과 함께 사라진다

## Examples

- `lab04` → VPC와 Subnet 생성, Rocky Linux 서버 생성과 공인 IP 할당, ACG 규칙 확인, 관리자 비밀번호 확인과 SSH 접속, 이름으로 검색하여 전부 반납
