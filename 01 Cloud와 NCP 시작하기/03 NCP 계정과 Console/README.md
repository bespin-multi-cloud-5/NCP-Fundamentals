# 01 Cloud와 NCP 시작하기 / 03 NCP 계정과 Console

계정을 생성하고 결제 수단을 등록한 뒤 이후 모든 실습을 진행할 콘솔 환경을 구성한다. 포털과 콘솔의 역할 구분, 리전과 플랫폼 설정이 콘솔 전체에 적용되는 구조를 함께 다룬다.

## What you will learn

- 가입 유형과 거주 국가 — 거주 국가가 결제 통화를 결정하며 가입 후 변경할 수 없다
- 결제 수단과 크레딧 — 등록해야 자원을 생성할 수 있고, 무료 크레딧은 자동 지급이 아니라 직접 신청한다
- 포털과 콘솔의 분리 — 담당 영역이 다르고 주소도 다르다
- 콘솔의 진입 경로 둘 — 서비스는 `Menu`, 계정과 결제는 상단의 로그인한 사용자 이름. 메뉴 표기 언어도 영역이 가른다
- 리전과 플랫폼 설정 — 콘솔 전체에 적용되고 로그인 사이에 유지되며, 리전 선택이 플랫폼을 결정한다

## Examples

- `lab01` → 회원 가입, 결제 수단 등록, 무료 체험 크레딧 신청, 리전과 플랫폼 설정, Menu 탐색, 크레딧 조회
