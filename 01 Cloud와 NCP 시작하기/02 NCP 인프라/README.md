# 01 Cloud와 NCP 시작하기 / 02 NCP 인프라

자원의 위치를 결정하는 리전과 존을 정리하고, Classic과 VPC 두 사용 환경의 관계를 확인한다. 이후 챕터의 전제가 되는 NCP 플랫폼의 성격을 다룬다.

## What you will learn

- 리전과 존이 각각 결정하는 것 — 자원이 위치할 국가와 리전 내 설비 위치
- 리전별 구성과 제약 — 멀티존과 VPC 환경은 한국, 일본, 싱가포르 3개 리전에서만 제공된다
- 서비스 종속 범위 — 존, 리전, 글로벌 세 단위의 구분
- 사용 환경 — Classic과 VPC는 자원을 상호 이동할 수 없고, 리전 선택이 환경을 결정한다
- AWS와의 대응성과 네트워크 우선 설계 — Default VPC가 없어 서버보다 네트워크를 먼저 구축한다
