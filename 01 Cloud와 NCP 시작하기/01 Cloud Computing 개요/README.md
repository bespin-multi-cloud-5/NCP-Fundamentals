# 01 Cloud와 NCP 시작하기 / 01 Cloud Computing 개요

온프레미스와 클라우드의 차이, 서비스 모델을 가르는 기준, 클라우드가 성립하는 근거를 정리한다. NCP의 서비스 카테고리에서 본 시리즈가 다루는 범위도 함께 확인한다.

## What you will learn

- 온프레미스와 클라우드의 차이 — 용량 결정 시점과 판단을 되돌리는 비용
- 서비스 모델(IaaS, PaaS, SaaS)을 가르는 기준과 계층별 관리 주체
- 클라우드가 성립하는 근거 — 자원 풀링, 탄력성, 사용량 기반 과금, API를 통한 제어
- 사용하지 않아도 보유하는 동안 요금이 부과되는 자원의 존재
- NCP의 서비스 카테고리와 본 시리즈가 다루는 다섯 영역
